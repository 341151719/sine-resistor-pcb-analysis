## 当前诊断状态（2026-09-08）

官方 OPA548/OPA1656 模型在正确的 PSpice 兼容设置下可以运行。已观察到
OPA548 启用并连接 4.7 Ω + 47 nF 负载时约 452 kHz 的小幅输出纹波，但它
只在 TP8 产生约 60 µVpp，不能解释实板上约 100--110 kHz、超过 10 Vpp 的
TP8 波形。对 10 个单点故障（反馈电阻、电容、焊桥、供电串联阻抗、去耦、
R5/R12 等）的当前局部模型测试均未复现目标波形。详见各假设目录中的
`hypothesis.md`、网表和日志；“本模型未复现”不等于已排除实物器件损坏、
多故障叠加或未建模的供电/回流动态。

## 复现约定

仿真通常使用 ngspice-42；TI PSpice 宏模型需要 `set ngbehavior=ps`，并且
某些官方模型需要显式 `TEMP`。每个故障目录都记录了实际命令和模型限制。
历史网表中可能保留当时机器的绝对路径，这是审计记录的一部分；在新机器
上运行前应根据目录位置调整 `.include` 路径。`.dat` 波形文件和环境安装包
没有纳入 Git，它们可由网表重新生成，避免仓库膨胀。

## 版本纪律

V7 目录作为原始加工基线保留；V8 是当前修正版工作状态，不应在没有新的
验证记录时覆盖。请用独立提交记录新的板改动、仿真假设和结论，并在
`CHANGELOG.md` 中补充面向人的摘要。
