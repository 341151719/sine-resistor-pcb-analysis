# 实验还原与可复现证据

本目录保存已经整理过、能够追溯到 KiCad 拓扑或 SPICE 运行结果的实验材料。
它不宣称已经找到实板 100–110 kHz 振荡的唯一物理根因。

## 建议阅读顺序

1. [`实板实验记录.md`](实板实验记录.md)：按实际排查顺序区分有效测量、
   作废测量、已否定假设和仍待闭环的问题。
2. [`早期错误复现/`](早期错误复现/)：复现 R10/E/S 裕量、错误示波器接地
   和 OPA ON 后的电流后果，同时保留“健康模型不能产生 105 kHz”的阴性基线。
3. [`主动审计/`](主动审计/)：解释旧 SPICE 为什么可能漏检状态型错误，并提供
   网表 lint、制造数据交叉检查和 H07/H08 修正模型。
4. [`../故障假设排查_20260908/H12_OPA548_ES_R5动态耦合/`](../故障假设排查_20260908/H12_OPA548_ES_R5动态耦合/)：
   E/S–R5 动态耦合的正式假设记录和 23 组扫描。

## 证据分级

| 项目 | 状态 | 可以得出的结论 |
|---|---|---|
| V7 R10=100 kΩ 与并联 10 kΩ | 定量复现 | 官方宏模型的 0.614 V 与实测 0.55–0.65 V 相符，说明关断裕量风险真实存在 |
| 示波器地夹接 TP8 | 强等效复现 | 该接法会把 U4B 输出重载，因此对应波形和增流数据必须作废 |
| 已存在 105 kHz 时 OPA ON | 后果复现 | 约 2 Vpk 输入足以产生约 69 mA 峰值取电；这不是 105 kHz 的发生模型 |
| 健康 OPA1656/OPA548 基线 | 阴性结果 | 当前模型不会自然产生实板的数伏级 100–110 kHz |
| H12 的约 453 kHz 模态 | 模型内阳性、目标阴性 | 证明 R5 可参与组合动态，但频率和 TP8 幅值都不匹配实板，不能视为根因复现 |
