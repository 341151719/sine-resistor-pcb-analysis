# H03 — R15 低值错料（首选 1 kΩ → 100 Ω）

## 物理错误与现有证据

V8 BOM 中 R15 是 `1.000kR` R0805，连接 U4 pin 6 的 `U4B_N` 到 AGND。
100 Ω 是常见 E 系列/标识或贴片料盘错误，属于只改变一个电阻本体的
可发生加工参数错误。尚无实测值证明或反驳，因此保留为待验证假设。

## 事前计算与预测

U4B 的名义非反相噪声增益为 `1 + R16/R15`。健康值为
`1 + 39k/1k = 40`；R15=100 Ω 时为 `1 + 39k/100 = 391`。
对相同 1 mV 启动脉冲，低频理想响应约从 40 mV 增至 391 mV。较低 R15
也增大反馈分压电流，但在百毫伏输入范围内仍远低于电阻功耗限制。单凭
比例变化没有 100--110 kHz 选频机制；若环路相位裕量不足，必须在 0.25--
0.5 ms 晚段观察持续振荡，若没有则只算启动放大/饱和。

## 仅改变项与基线

只将 R15 改为 100 Ω；R16=39 kΩ、C39 等 DNP、R5=100 Ω、4.7 Ω+47 nF
负载、J2/U4=±10 V、J1/OPA548=±5 V、E/S=V−+0.6 V 均不变。健康
基线副本在 `../baseline_official/`；本目录含独立 common、deck、log、
trace。

## 工具与命令

ngspice-42（`/usr/bin/ngspice`），官方 TI OPA548/OPA1656 宏模型，
`.spiceinit` 为 `set ngbehavior=ps`。从本目录运行：

```text
timeout 30s ngspice -b -o results/fixed_H03_R15_100R.log fixed_H03_R15_100R.cir
```

瞬态 0.5 ms、最大步长 0.05 µs，单个 1 mV/2 µs kick；晚期窗 0.25--
0.5 ms，包含超过 50 个 100 kHz 周期。

## 结果与工作点可信度

`fixed_H03_R15_100R.log` 以 EXIT 0 完成（约 10k 数据行），无收敛、
奇异矩阵或步长失败告警。晚段 `TP8_MAX = TP8_MIN = 0.191285 V`，故
`TP8 late Vpp = 0 V`；启动窗口为约 0.191285--0.521660 V。`U4O` 晚段
同样为常值，`U4O late Vpp = 0 V`；`OPA548 OUT` 约 −4.6373 V 常值，
晚段没有可测零交叉频率。J1 电源电流约 −57.18/+57.18 mA，J2 约
−7.806/+7.800 mA；官方 OPA548 OFF IQ 异常，这些数值只作模型工作点
诊断，不能作实板电流证据。

## 判断

**本模型未复现。** R15=100 Ω 确实放大启动响应，但在固定 J1=±5/J2=±10
场景下没有 TP8 >10 Vpp、100--110 kHz 持续波形或晚段DC继续饱和。该结论
只排除“此单一低值在当前官方宏模型/拓扑中足以产生目标”，不泛化为实板
不存在该错料。

## 下一步

只有出现 >10 Vpp 候选时才缩小最大步长并做 R5 100 Ω/开路对照；否则转到
R15 漏装或真实焊桥/供电路径，不盲扫更多电阻值。
