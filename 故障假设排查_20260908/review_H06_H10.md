# Cross-review of H06–H10

审查对象是另一 agent 在本目录完成的 H06–H10 独立子目录；本文件只作
交叉检查，不改变其原始 TI 模型。统一目标是 J2/U4 `+/-10 V`、J1/
OPA548 `+/-5 V`、OPA548 OFF、R5=100 ohm、TP8（R5之前）在晚段出现
100--110 kHz 且 >10 Vpp。所有 deck 都只给 1 mV / 2 us 启动 kick，
没有人工105 kHz源。

所有“无频率”均不是把频率当作0 Hz测量，而是晚段没有稳定的过零列，
所以不能定义振荡频率。各日志的 accepted rows 覆盖完整 0.5 ms，晚段
窗0.25--0.5 ms足以容纳约50个100 kHz周期。未发现任何 TP8 >10 Vpp
候选，故没有触发更小步长复核。

## 有效性审查与必要修正

* H06 的 C39 节点确实跨 `R16O--R16N`（VCMD/U4B_N），单独参数修改；
  22 pF 为原理图值误装，220 pF 明确标为压力例。官方 OFF IQ异常已在
  hypothesis.md 中限定，结论不能外推到R10/光耦组合。
* H07 保留了 U4/J2 两轨的 extracted R/L、C15/C11/C16/C10/C12 与J1
  源阻尼；RAPS=1/10 Ω代表“该聚合串联段高阻”，不能定位是磁珠本体、
  焊点还是铜路。三例虽然出现 dynamic/true/source gmin stepping failed
  提示，但随后都明确 `Transient op started/finished successfully` 并有
  完整数据，故可作为带数值警告的有效负结果，不能只凭 EXIT 0。
* H08 初始版本的首例曾因 PGND 初始时间点失败；另一 agent 已将 nominal
  C15=100 nF 先运行并更新 `H08_decoupling.log`，当前主日志三例均有
  `Transient op finished successfully` 和完整数据。旧的
  `H08_test_fixed.log` 是已被该修正版取代的诊断日志，含0行失败记录，
  不应与主结果混读。主日志仍有gmin stepping提示，已在结论中保留限制。
* H09 原始 deck曾引用旧 temp 目录的绝对 `fault_fixed_common.inc`；已
  复制同一 common 到 H09 子目录并改为相对 include，`H09_R5_local.log`
  复跑 EXIT 0，三例各10084行、指标与原始log一致。H09因此满足独立
  可复跑要求；绝对官方模型路径仍保留为只读源模型路径。
* H10 是独立拓扑，R12只位于OPA548输出与C4 47 nF之间，R5/R16/C39
  未叠加；三例均完整。其 OUT 的约−4.637 V平坦OFF状态来自官方宏模型，
  不应解释为实板输出级行为。

## 总判断

H06、H07、H08、H09、H10 均在声明的官方模型/简化板级拓扑适用范围内
完成了单一故障测试，均未复现目标大幅持续振荡。H07/H08 的负结果带有
启动求解警告，H09/H10 受OFF宏模型输出限制；这些是有效性限定，不是
把模型缺功能当成硬件安全。结果只支持：在当前 `OPA548 OFF + J2±10 +
J1±5 + R5=100 Ω` 条件中，这五个单故障各自没有产生报告的 TP8 波形；
不能排除实板器件损伤、未建模光耦状态、多个错误叠加或不同频率的实际
电源阻抗。
