# 故障假设排查（2026-09-08）

本目录是本轮 PCB 故障假设的独立审计目录，不修改 PCB、KiCad 工程、原始
TI 宏模型或旧 SPICE deck。主场景固定为：U4/J2 `+/-10 V`、OPA548/J1
`+/-5 V`、OPA548 `E/S = V- + 0.6 V`（OFF）、`R5 = 100 ohm`、真实的
`4.7 ohm + 47 nF`输出网络，观察点为 TP8（U4 输出、R5 之前）。每个
假设先做物理/数量级预测，再用不超过 3 个固定参数 case 的 ngspice-42
瞬态复核；每个 case 以 30 s 为限，瞬态至少 0.5 ms。没有人为注入
105 kHz 极点或正弦源。

## 模型有效性边界

官方 `OPA548.LIB` 和 `OPA1656.LIB` 在 ngspice-42 需本目录或子目录的
`.spiceinit`（`set ngbehavior=ps`）兼容设置。OPA548 OFF 宏模型的静态
电流此前已明显偏离数据手册的 shutdown IQ；因此所有 OFF 供电电流只作
“宏模型工作点诊断”，不能解释成实板电流。`EXIT 0` 只表示数值运行结束，
还必须检查 KVL、波形是否饱和、是否存在足够长的稳定晚期振荡及频率。

## 本目录结构

* `baseline_official/`：复制的已验证健康官方模型基线（不改源文件）。
* `H01_R16_十倍错料/`、`H02_R16_漏装/`、`H03_R15_低值/`、
  `H04_R15_漏装/`、`H05_U4B输入输出焊桥/`、`H11_U4B_pin5_pin6焊桥/`：
  本轮由 Luna Max 负责；H11 是对 H04 超时后的独立邻近脚补充。
* `H06-H10/`：由另一 agent 独立建立；本 agent 只在其完成后写交叉审查，
  不直接修改其假设目录。
* `H12_OPA548_ES_R5动态耦合/`：新增的组合机制审计。它有意解除统一基线中
  “OPA548 固定 OFF”的前提，用有限 E/S 状态、TLP185、R10、R5 和 J1/PGND
  网络检查此前模型盲区；不把 H12 作为新的单一加工错误。

固定基线已复制到本目录的 `baseline_official/`；其中保留了可审计的
`fixed_H0_R16_39k.cir`、`fault_fixed_common.inc` 和运行日志。原始临时
审计目录不属于 GitHub 归档，避免把机器临时文件带入版本历史。

## 判定词

“本模型未复现”表示 deck 在适用边界内收敛但没有目标波形；“不适用”
表示该物理错误无法由当前官方宏模型/简化拓扑有意义表示；“DC饱和”与
“持续振荡”严格分开；“未完成”只用于运行失败或证据不足。H12 的
“组合模态”只表示模型中存在高频耦合模式；其约 453 kHz 结果不能等同于
实板 100–110 kHz 根因。
