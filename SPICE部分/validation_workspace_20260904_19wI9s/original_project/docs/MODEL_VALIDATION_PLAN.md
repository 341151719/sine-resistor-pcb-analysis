# 严格仿真计划

本项目默认不是只跑一条“能收敛”的 transient，而是用分层对照与应力扫参来检查合理性。

## 1. 三层模型对照

1. `ideal_*`：理想合成阻抗 `V=Rx*i`，用于理论基准；
2. `behavioral_*`：上一轮行为级电流检测 + 乘法器 + 功率跟随器；
3. `full_*`：全元器件接入版，OPA548/AD633/INA149/OPA1656 以子电路接入。

## 2. 固定阻值测试

- `Rtarget = 100, 20, 7.2, 5, 1 Ω`
- 重点确认：
  - `Rx=0` 穿越点；
  - `Rtarget=1 Ω` 时 `Rx=-6.2 Ω`；
  - 高阻态小电流下 `Reff` 重建是否出现数值误差。

## 3. 调制频率边界

- `fm = 10, 30, 100, 300, 1000 Hz`
- 重点确认 DAC/AD633/OPA1656/OPA548 surrogate 引入的一阶带宽和相位滞后没有让闭环失稳。

## 4. 声学激励频率扫描

- `fa = 60, 90, 120, 180, 300 Hz`
- 特别关注 `fs=90 Hz` 附近速度和位移。

## 5. 声压应力扫描

- `Pamp = 1, 5 Pa`。
- 本 v3.3 包默认删除 `Pamp > 5 Pa` 的应力测试，不再生成更高声压 case。
- 同时跑固定 `1 Ω` 和调制 `1~100 Ω`。
- 检查输出饱和、限流、位移是否超过 `±4 mm`。

## 6. 不通过判据建议

建议把下面几项视作需要重设计/降额：

- `xmax_ratio_pk > 1`；
- OPA548 surrogate 出现长时间饱和；
- `reff_rms_err_tail_ohm` 在非饱和时明显超过 `0.1 Ω`；
- `Iport` 接近或超过设定限流；
- `Rtarget=1 Ω` 低阻/负阻段出现持续振荡。
