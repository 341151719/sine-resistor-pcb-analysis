# Acoustic stress limit v3.3

This package intentionally removes all acoustic stress cases above 5 Pa from the default sweep suite.

## Remaining acoustic stress cases

- `full_stress_pa1_fixed1ohm`
- `full_stress_pa1_mod`
- `full_stress_pa5_fixed1ohm`
- `full_stress_pa5_mod`

Higher-pressure acoustic stress cases are not generated by `scripts/run_sweeps.py`, and old generated high-pressure case folders are not included in this package.

The purpose is to keep the project focused on the intended operating envelope and avoid interpreting high-pressure boundary/failure cases as normal validation cases.

Run from scratch with:

```bash
python scripts/run_sweeps.py --clean
```

Generate netlists only with:

```bash
python scripts/run_sweeps.py --clean --write-only
```
