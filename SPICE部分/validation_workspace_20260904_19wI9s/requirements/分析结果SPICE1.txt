

下面给出一个**可落地的一通道原型方案**：把这只 8 Ω 动圈单元当作“被外界声压驱动的电声膜/反射体”，在其端子上接一个**有源合成阻抗 / 广义负阻抗变换器**，使声学侧通过 \(B\ell\) 耦合看到的电学阻尼随时间按正弦变化。

> **先说关键结论**：  
> 如果“被动性”指**完全不接外部电源、只用 R/L/C/开关/无源网络**，那么你要求的 \(R_\mathrm{dc}\) 从 \(7.2\,\Omega\) 降到 \(1\,\Omega\) 是**物理上做不到的**：短路端子时，动生电流回路的最小串联电阻就是线圈铜阻 \(R_e=7.2\,\Omega\)。  
> 要得到等效 \(1\,\Omega\)，外接电路必须合成
>
> \[
> R_x(t)=R_\mathrm{target}(t)-R_e=1-7.2=-6.2\,\Omega
> \]
>
> 也就是**负电阻**。因此本方案的正确表述应是：声学上它不接“音频驱动信号”，仍由外界声压激发；但电学端接入一个**有源、供电的合成阻抗电路**，用来实时改变反射/吸收特性。

## 1. 设计目标重写

你的目标可以写成：

\[
R_\mathrm{target}(t)
=
R_0
+
A_1\sin(2\pi f_1 t+\phi_1)
+
A_2\sin(2\pi f_2 t+\phi_2)
\]

并限制：

\[
1\,\Omega \le R_\mathrm{target}(t)\le 100\,\Omega
\]

其中：

\[
10\,\text{Hz}\le f_1,f_2 \le 1000\,\text{Hz}
\]

由于线圈铜阻为：

\[
R_e=7.2\,\Omega
\]

所以外接有源合成阻抗应为：

\[
R_x(t)=R_\mathrm{target}(t)-R_e
\]

因此：

\[
R_x(t)\in[-6.2\,\Omega,\;92.8\,\Omega]
\]

这意味着外接电路必须同时能合成：

- 正电阻：\(0\sim92.8\,\Omega\)
- 零电阻：当 \(R_\mathrm{target}=7.2\,\Omega\) 时，\(R_x=0\)
- 负电阻：最低到 \(-6.2\,\Omega\)

**所以不建议用传统“电流源式” \(i=v/R_x(t)\) 方案**，因为当 \(R_x(t)\to0\) 时会奇异。这里选择更稳妥的**电压型合成阻抗**：

\[
v_\mathrm{port}=R_x(t)\,i_\mathrm{port}
\]

当 \(R_x=0\) 时，它自然退化为“有源短路”；当 \(R_x<0\) 时，它就是负阻抗。

## 2. 用你的 T/S 参数建立电声节点模型

你给出的核心参数：

| 参数 | 数值 |
|---|---:|
| 线圈直流电阻 \(R_e\) | \(7.2\,\Omega\) |
| 线圈电感 \(L_e\) | \(0.2\,\mathrm{mH}\) |
| 力因数 \(B\ell\) | \(4.6\,\mathrm{T\,m}\) |
| 振动质量 \(M_\mathrm{ms}\) | \(5.7\,\mathrm{g}=0.0057\,\mathrm{kg}\) |
| 谐振频率 \(f_s\) | \(90\,\mathrm{Hz}\) |
| 机械 Q \(Q_\mathrm{ms}\) | \(2.29\) |
| 活塞面积 \(S_d\) | \(50\,\mathrm{cm^2}=0.005\,\mathrm{m^2}\) |
| 最大线性位移 | \(\pm4\,\mathrm{mm}\) |

角谐振频率：

\[
\omega_s=2\pi f_s=565.49\,\mathrm{rad/s}
\]

机械顺性：

\[
C_\mathrm{ms}
=
\frac{1}{M_\mathrm{ms}\omega_s^2}
=
5.486\times10^{-4}\,\mathrm{m/N}
\]

机械刚度：

\[
K_\mathrm{ms}
=
\frac{1}{C_\mathrm{ms}}
\approx
1823\,\mathrm{N/m}
\]

机械损耗：

\[
R_\mathrm{ms}
=
\frac{\omega_s M_\mathrm{ms}}{Q_\mathrm{ms}}
=
1.408\,\mathrm{N\,s/m}
\]

电声耦合方程采用常见动圈模型：

\[
v_e
=
R_e i_e
+
L_e\frac{di_e}{dt}
+
B\ell\,u
\]

\[
M_\mathrm{ms}\frac{du}{dt}
+
R_\mathrm{ms}u
+
\frac{1}{C_\mathrm{ms}}\int u\,dt
+
B\ell\,i_e
=
S_d p_\mathrm{ext}(t)
\]

其中：

- \(u\)：膜片速度，单位 \(\mathrm{m/s}\)
- \(p_\mathrm{ext}\)：外界声压
- \(S_d p_\mathrm{ext}\)：作用在膜片上的等效力
- \(B\ell u\)：反电动势
- \(B\ell i_e\)：电流产生的反作用力

忽略线圈电感时，由电端形成的等效机械阻尼为：

\[
R_\mathrm{em}(t)
=
\frac{(B\ell)^2}{R_\mathrm{target}(t)}
\]

因此：

| \(R_\mathrm{target}\) | \(R_\mathrm{em}=(B\ell)^2/R_\mathrm{target}\) |
|---:|---:|
| \(1\,\Omega\) | \(21.16\,\mathrm{N\,s/m}\) |
| \(7.2\,\Omega\) | \(2.94\,\mathrm{N\,s/m}\) |
| \(50.5\,\Omega\) | \(0.419\,\mathrm{N\,s/m}\) |
| \(100\,\Omega\) | \(0.212\,\mathrm{N\,s/m}\) |

也就是说，当你把等效电阻从 \(100\,\Omega\) 拉到 \(1\,\Omega\) 时，电磁阻尼大约增加：

\[
\frac{21.16}{0.212}\approx100
\]

这会显著改变膜片的声学边界条件。

更准确地，考虑线圈电感：

\[
Z_\mathrm{em}(\omega,t)
=
\frac{(B\ell)^2}
{R_\mathrm{target}(t)+j\omega L_e}
\]

在 \(f_s=90\,\mathrm{Hz}\) 附近：

\[
\omega L_e
=
2\pi\cdot90\cdot0.2\,\mathrm{mH}
\approx0.113\,\Omega
\]

可以忽略。但在 \(4\,\mathrm{kHz}\)：

\[
\omega L_e
\approx5.03\,\Omega
\]

所以如果你希望在几 kHz 以上仍然严格保持 \(1\sim100\,\Omega\) 的等效电阻，后续版本应加入**负电感合成**：

\[
v_x(t)=R_x(t)i-L_e\frac{di}{dt}
\]

但第一版不建议加负电感，因为微分环节会放大噪声并明显增加稳定性风险。

## 3. 节点描述法：系统级 MNA 方程

定义节点和变量：

| 名称 | 含义 |
|---|---|
| \(0\) | 电路地 / 喇叭负端 |
| \(a\) | 喇叭正端 / 合成阻抗端口 |
| \(i_z\) | 进入合成阻抗端口的电流 |
| \(i_e\) | 通过线圈的电流 |
| \(u\) | 膜片速度 |
| \(x\) | 膜片位移 |
| \(p(t)\) | 外部声压 |

外接合成阻抗关系：

\[
v_a=R_x(t)i_z
\]

线圈与反电动势：

\[
v_a
=
R_e i_e
+
L_e\frac{di_e}{dt}
+
B\ell\,u
\]

端口 KCL：

\[
i_z+i_e=0
\]

机械方程：

\[
M_\mathrm{ms}\frac{du}{dt}
+
R_\mathrm{ms}u
+
K_\mathrm{ms}x
+
B\ell\,i_e
=
S_d p(t)
\]

位移关系：

\[
\frac{dx}{dt}=u
\]

目标电阻：

\[
R_\mathrm{target}(t)
=
\operatorname{clip}
\left[
R_0
+
A_1\sin(2\pi f_1t+\phi_1)
+
A_2\sin(2\pi f_2t+\phi_2),
1,
100
\right]
\]

外接阻抗：

\[
R_x(t)=R_\mathrm{target}(t)-7.2
\]

如果只用一个正弦覆盖 \(1\sim100\,\Omega\)，可取：

\[
R_\mathrm{target}(t)
=
50.5+49.5\sin(2\pi f_m t)
\]

如果用两个正弦叠加，建议满足：

\[
A_1+A_2 \le 49.5\,\Omega
\]

否则会发生裁剪，导致额外边带和非正弦调制。

## 4. 选择的电路拓扑

### 4.1 总体结构

采用**电压型合成阻抗**：

```text
外界声压
   ↓
动圈膜片机械运动
   ↓
反电动势 Bℓu
   ↓
喇叭端子 SPK+
   ↓
有源合成阻抗电路：v = R_x(t) · i
```

实际电路由五个部分组成：

1. **功率运放级**：负责在喇叭端子上施加所需电压。
2. **电流检测电阻 \(R_s\)**：检测进入合成阻抗的端口电流。
3. **电流检测放大器**：把小电压 \(v_s=R_s i\) 放大。
4. **四象限模拟乘法器**：实现 \(i \times R_x(t)\)。
5. **MCU/DAC 正弦发生器**：生成 \(R_\mathrm{target}(t)\)，支持单正弦或双正弦叠加。

## 5. 实现级节点定义

实际电路节点：

| 节点 | 说明 |
|---|---|
| `GND` | 喇叭负端、模拟地 |
| `SPK` | 喇叭正端，即合成阻抗端口 |
| `DRV` | 功率运放输出端 |
| `VSENSE+` | 电流检测电阻靠 `SPK` 一侧 |
| `VSENSE-` | 电流检测电阻靠 `DRV` 一侧 |
| `ISIG` | 电流检测放大后的信号 |
| `VK` | 电阻命令电压，代表 \(R_x/10\) |
| `MUL` | AD633 乘法器输出 |
| `VCMD` | 功率运放目标输出电压 |
| `DAC_R` | MCU DAC 输出，代表 \(R_\mathrm{target}\) |

电流检测电阻：

\[
R_s=0.1\,\Omega
\]

端口电流定义为从 `SPK` 进入电路：

\[
i_p=\frac{V_\mathrm{SPK}-V_\mathrm{DRV}}{R_s}
\]

检测电压：

\[
v_s=V_\mathrm{SPK}-V_\mathrm{DRV}=R_s i_p
\]

电流检测放大倍数取 50：

\[
v_I=50v_s=50R_s i_p=5i_p
\]

命令电压定义：

\[
V_K=\frac{R_x(t)}{10}
\]

AD633 输出关系为：

\[
V_\mathrm{MUL}
=
\frac{v_I V_K}{10}
\]

后级放大 20 倍：

\[
V_\mathrm{CMD}
=
20V_\mathrm{MUL}
=
20\frac{(5i_p)(R_x/10)}{10}
=
R_x i_p
\]

功率运放闭环强制：

\[
V_\mathrm{SPK}\approx V_\mathrm{CMD}
\]

因此：

\[
V_\mathrm{SPK}\approx R_x(t)i_p
\]

这正是目标合成阻抗。

## 6. 为什么选这种“电压型”方案，而不是普通 NIC？

传统负阻抗变换器常写成某种固定比例：

\[
R_\mathrm{in}=-kR
\]

但你的目标有三个麻烦：

1. \(R_x(t)\) 要从 \(-6.2\,\Omega\) 到 \(92.8\,\Omega\) 连续变化。
2. 中间要穿过 \(0\,\Omega\)。
3. 变化速度最高 \(1000\,\mathrm{Hz}\)，且端口信号本身可能在音频范围。

如果用电流源式：

\[
i=\frac{v}{R_x(t)}
\]

当 \(R_x\to0\) 时会要求无限大电流，实际必然崩溃或削顶。  
所以本方案改成：

\[
v=R_x(t)i
\]

这样：

- \(R_x>0\)：合成正电阻
- \(R_x=0\)：合成短路
- \(R_x<0\)：合成负电阻

更加适合穿越零点。

### 7.2 为什么不选 LM3886 / TDA7294 作为第一版？

LM3886、TDA7294 都是音频功放 IC，便宜、功率大，但不适合第一版合成负阻抗实验：

- 它们主要面向音频功率放大，不是精密功率运放。
- 很多典型应用要求较高闭环增益，LM3886 数据资料中的设计讨论也以常规音频功放增益范围为基础。([ti.com](https://www.ti.com/lit/ds/symlink/lm3886.pdf?ref_url=https%253A%252F%252Fwww.ti.com%252Fproduct%252Fde-de%252FLM3886&ts=1778917978836))
- 合成阻抗需要低频/DC 精确关系：

\[
v=R(t)i
\]

而不是单纯放大音频输入。
- 负阻抗负载下更容易出现相位裕度问题。
- 第一版调试需要电流限制、禁用、热状态等保护接口，OPA548 更合适。

如果后续证明算法和声学效果成立，再考虑用：

- OPA549：更高电流，代价更高。OPA548 官方页面也把 OPA549列为更高电流替代器件。([ti.com](https://www.ti.com/product/OPA548))
- 离散 MOSFET AB 级
- Class-D 电流/电压合成桥

### 7.3 模拟乘法器：AD633

推荐：

```text
U2 = AD633ARZ
```

- 四象限模拟乘法器，正负信号都能处理。
- 典型关系：

- 1 MHz 带宽、20 V/µs 压摆率，足够覆盖 \(10\sim1000\,\mathrm{Hz}\) 的阻值调制以及音频范围内的电流信号。

### 7.6 MCU / DAC：STM32G431CBT6

推荐：

```text

```

DAC 映射建议：

让 MCU 输出：

\[
V_\mathrm{DAC}
=
3.000
\frac{R_\mathrm{target}-1}{99}
\]

其中 \(V_\mathrm{DAC}\in[0,3.0]\,\mathrm{V}\)。

模拟缩放得到：

\[
V_K
=
3.3V_\mathrm{DAC}-0.62
\]

检查：

当 \(R_\mathrm{target}=1\,\Omega\)：

\[
V_\mathrm{DAC}=0
\]

\[
V_K=-0.62\,\mathrm{V}
\]

对应：

\[
R_x=10V_K=-6.2\,\Omega
\]

当 \(R_\mathrm{target}=100\,\Omega\)：

\[
V_\mathrm{DAC}=3.0\,\mathrm{V}
\]

\[
V_K=9.28\,\mathrm{V}
\]

对应：

\[
R_x=92.8\,\Omega
\]

当 \(R_\mathrm{target}=7.2\,\Omega\)：

\[
V_K=0
\]

对应外接阻抗为 \(0\,\Omega\)，即端口短路。

## 9. 排除的元器件 / 方案

| 被排除方案 | 排除原因 |
|---|---|
| 纯无源 R/L/C 网络 | 不能把等效电阻降到 \(R_e=7.2\,\Omega\) 以下。 |
| 继电器/模拟开关电阻阵列 | 只能合成正电阻或短路，不能合成 \(-6.2\,\Omega\)。并且 10–1000 Hz 连续正弦变化不适合机械继电器。 |
| 数字电位器直接接端口 | 端口电流、电压、功率不够；不能处理负阻抗；音频电流下失真和损坏风险高。 |
| 数字电位器放在 NIC 反馈里 | 可行但跨越 \(R_x=0\) 很麻烦，更新有毛刺，控制复杂。 |
| JFET/MOSFET 线性可变电阻 | 双向小信号尚可，功率和线性都不够；无法直接生成负阻抗。 |
| 光耦电阻 / Vactrol | 太慢，不适合最高 \(1000\,\mathrm{Hz}\) 阻值调制。 |
| LM13700 OTA | 成本低，但线性范围、温漂、校准难度不如 AD633；第一版不建议。 |
| Class-D H 桥 | 效率高，但控制、EMI、采样延迟、稳定性都更复杂；建议第二版再做。 |
| LM3886 / TDA7294 | 作为音频功放很好，但不是为 DC 精确合成阻抗设计；负阻抗环路调试风险高。 |

## 10. SPICE：理想合成阻抗 + 电声膜模型

下面是一个 **ngspice / KiCad-ngspice 风格**的行为模型。  
它用于验证：

\[
R_\mathrm{eff}(t)=R_e+R_x(t)=R_\mathrm{target}(t)
\]

并观察膜片速度变化。

> 注意：这是系统行为模型，不是 OPA548 晶体管级模型。实际 PCB 前应再引入 OPA548 官方宏模型进行相位裕度验证。OPA548 官方页面说明有 SPICE macromodel 可用于分析。([ti.com](https://www.ti.com/product/OPA548))

```spice
* ------------------------------------------------------------
* Active acoustic impedance loudspeaker shunt
* Ideal synthetic impedance version
* Compatible target: ngspice / KiCad-ngspice style
* ------------------------------------------------------------

.title Electrodynamic passive membrane with modulated synthetic impedance

* ---------- Parameters from user ----------
.param Re   = 7.2
.param Le   = 0.2m
.param Bl   = 4.6
.param Mms  = 5.7m
.param fs   = 90
.param Qms  = 2.29
.param Sd   = 5m
.param TWOPI = 6.283185307179586

* Derived mechanical values
.param W0   = {TWOPI*fs}
.param Cms  = {1/(Mms*W0*W0)}
.param Rms  = {W0*Mms/Qms}
.param Kms  = {1/Cms}

* ---------- Modulation settings ----------
* One sine spanning 1 to 100 ohm:
.param R0   = 50.5
.param A1   = 49.5
.param fm1  = 100
.param ph1  = 0

* Optional second sine; keep A1 + A2 <= 49.5 to avoid clipping
.param A2   = 0
.param fm2  = 317
.param ph2  = 0

.param RMIN = 1
.param RMAX = 100

.func Rraw(t) { R0 + A1*sin(TWOPI*fm1*t + ph1) + A2*sin(TWOPI*fm2*t + ph2) }
.func Rt(t)   { min(max(Rraw(t), RMIN), RMAX) }
.func Rx(t)   { Rt(t) - Re }

* ---------- Acoustic excitation ----------
* 1 Pa at 120 Hz, just for test.
* 1 Pa ~= 94 dB SPL.
.param Pamp = 1
.param fa   = 120

* ---------- Ideal external synthetic impedance ----------
* Port node is SPK relative to ground.
* V(SPK) = Rx(time) * I(VZ)
* VZ is a 0 V current-sense source.
VZ SPK NZ 0
BZ NZ 0 V = { Rx(time)*I(VZ) }

* ---------- Voice coil electrical model ----------
* SPK -> Le -> Re -> current sense -> motional EMF -> ground
LVC SPK NL {Le}
RVC NL NR {Re}
VCOIL NR NEMF 0
BBEMF NEMF 0 V = { Bl*V(VEL) }

* ---------- Mechanical mobility analogy ----------
* Node VEL voltage = cone velocity u, in m/s.
* Current = mechanical force, in N.
*
* Mass:
CMASS VEL 0 {Mms}

* Mechanical damping:
* I = V/R = Rms*u, so resistor value is 1/Rms.
RDAMP VEL 0 {1/Rms}

* Compliance:
* Inductor current = displacement/Cms.
LCOMP VEL 0 {Cms}

* Small leakage for convergence
RLEAK VEL 0 1e9

* External acoustic force F = Sd * p
* Inject force current into VEL node.
BPRESS 0 VEL I = { Sd*Pamp*sin(TWOPI*fa*time) }

* Electromagnetic reaction force.
* Sign chosen so shorted coil gives damping for positive velocity.
BMOTOR VEL 0 I = { -Bl*I(VCOIL) }

* ---------- Probes ----------
BRT    RTNODE   0 V = { Rt(time) }
BRX    RXNODE   0 V = { Rx(time) }
BREM   REMNODE  0 V = { Bl*Bl/Rt(time) }
BQEFF  QNODE    0 V = { W0*Mms/(Rms + Bl*Bl/Rt(time)) }

* Effective total electrical resistance, numerically:
* Re + V(SPK)/I(VZ)
* Add tiny current in denominator for numerical safety.
BREFF  REFFNODE 0 V = { Re + V(SPK)/(I(VZ)+1e-15) }

* ---------- Analysis ----------
.tran 0 20m 0 2u

* Basic output.
.print tran V(RTNODE) V(RXNODE) V(REFFNODE) V(REMNODE) V(QNODE) V(VEL)

.end
```

## 11. SPICE 预期结果 / 验收表

若设置：

\[
R_\mathrm{target}(t)=50.5+49.5\sin(2\pi\cdot100t)
\]

则周期为：

\[
T_m=10\,\mathrm{ms}
\]

关键时刻应得到：

| 时间 | \(\sin(2\pi f_mt)\) | \(R_\mathrm{target}\) | \(R_x=R_\mathrm{target}-7.2\) | 说明 |
|---:|---:|---:|---:|---|
| \(0\,\mathrm{ms}\) | 0 | \(50.5\,\Omega\) | \(43.3\,\Omega\) | 中间值 |
| \(2.5\,\mathrm{ms}\) | +1 | \(100\,\Omega\) | \(92.8\,\Omega\) | 最大阻值 |
| \(5\,\mathrm{ms}\) | 0 | \(50.5\,\Omega\) | \(43.3\,\Omega\) | 中间值 |
| \(7.5\,\mathrm{ms}\) | -1 | \(1\,\Omega\) | \(-6.2\,\Omega\) | 最小等效阻值，外部为负阻 |
| \(10\,\mathrm{ms}\) | 0 | \(50.5\,\Omega\) | \(43.3\,\Omega\) | 回到中间值 |

对应电磁机械阻尼：

| \(R_\mathrm{target}\) | \(R_\mathrm{em}\) | 近似总 Q |
|---:|---:|---:|
| \(1\,\Omega\) | \(21.16\,\mathrm{N\,s/m}\) | \(0.143\) |
| \(7.2\,\Omega\) | \(2.94\,\mathrm{N\,s/m}\) | \(0.742\) |
| \(50.5\,\Omega\) | \(0.419\,\mathrm{N\,s/m}\) | \(1.765\) |
| \(100\,\Omega\) | \(0.212\,\mathrm{N\,s/m}\) | \(1.991\) |

其中：

\[
Q_\mathrm{eff}
\approx
\frac{\omega_s M_\mathrm{ms}}
{R_\mathrm{ms}+(B\ell)^2/R_\mathrm{target}}
\]

这个表是很好的第一阶段验收标准：  
SPICE 中 `V(RTNODE)` 和 `V(REFFNODE)` 应基本重合。

## 12. 实现级 SPICE：对应实际模拟乘法电路

下面这个片段把前面的理想阻抗 `BZ` 换成“电流检测 + 乘法器 + 功率运放”的行为等效。  
可把上一份 netlist 中的这一段：

```spice
VZ SPK NZ 0
BZ NZ 0 V = { Rx(time)*I(VZ) }
```

替换为以下电路。

```spice
* ------------------------------------------------------------
* Implementation-level behavioral synthetic impedance
* DRV -- RSH -- SPK
* Current defined as entering from SPK into the circuit.
* ------------------------------------------------------------

.param RSH = 0.1

* Power op-amp output to port through current shunt
RSHUNT DRV SPK {RSH}

* Current sense signal:
* Vs = V(SPK)-V(DRV) = RSH * ip
* Gain 50 => ISIG = 50*Vs = 5*ip
EISIG ISIG 0 VALUE = { 50*V(SPK,DRV) }

* Resistance command:
* VK = Rx/10
BVK VK 0 V = { Rx(time)/10 }

* AD633 ideal multiplication:
* MUL = ISIG * VK / 10
BMUL MUL 0 V = { V(ISIG)*V(VK)/10 }

* Post gain = 20:
* VCMD = 20*MUL = Rx*ip
EPOST VCMD 0 VALUE = { 20*V(MUL) }

* Simplified OPA548 closed-loop follower with saturation.
* It drives DRV so that SPK follows VCMD.
* For final simulation replace this with OPA548 macromodel.
BOPA DRV 0 V = { min(max(1e5*(V(VCMD)-V(SPK)), -16), 16) }

* Optional snubber, approximate
RSNUB DRV NSNUB 4.7
CSNUB NSNUB 0 47n
```

这个行为模型的核心验证是：

\[
V_\mathrm{SPK}\approx V_\mathrm{CMD}=R_x(t)i_p
\]

其中：

\[
i_p=\frac{V_\mathrm{SPK}-V_\mathrm{DRV}}{R_s}
\]

```c

    Rbias
  + A1 * sinf(2*pi*f1*t + phi1)
```

## 15. 稳定性与安全边界

这是负阻抗系统，必须严肃对待稳定性。

### 15.1 总等效电阻必须保持正值

虽然外接电路可以是负电阻：

\[
R_x<0
\]

但总目标：

\[
R_\mathrm{target}=R_e+R_x
\]

必须满足：

\[
R_\mathrm{target}>0
\]

建议第一版调试时先限制：

\[
R_\mathrm{target}\ge5\,\Omega
\]

确认稳定后再降到：

\[
3\,\Omega
\]

最后再尝试：

\[
1\,\Omega
\]

### 15.2 线圈铜阻会随温度变化

线圈热了以后 \(R_e\) 会升高。  
如果你仍然按固定 \(7.2\,\Omega\) 去抵消，实际 \(R_\mathrm{target}\) 会偏离。

建议 MCU 内部使用：

\[
R_x(t)=R_\mathrm{target}(t)-R_{e,\mathrm{est}}(t)
\]

第一版可手动校准：

```text
上电低电流测量 Rdc
写入 Re_cal
```

第二版可以做在线估计。

### 15.3 OPA548 热耗散

当 \(R_x=-6.2\,\Omega\) 且端口电流较大时，有源电路可能向电端供能。  
例如 \(i=1\,\mathrm{A}\) 时：

\[
P_x=R_xi^2=-6.2\,\mathrm{W}
\]

负号表示外接电路在供能。  
因此它不是“无源热耗散器”，必须靠 OPA548 和电源处理能量流。

### 15.4 必须有硬件关断

建议：

```text
|ISIG| 超限 → 比较器 → OPA548 E/S 关断
|SPK| 超限 → 比较器 → OPA548 E/S 关断
MCU watchdog fault → OPA548 E/S 关断
温度过高 → OPA548 E/S 关断
```

## 18. 调试流程

### 阶段 1：不接喇叭，只接假负载

用一个小信号源模拟反电动势：

```text
信号源 → 10 Ω 串联 → SPK
```

观察：

\[
\frac{V_\mathrm{SPK}}{I_\mathrm{port}}
\]

是否等于：

\[
R_x(t)
\]

先测试固定值：

```text
Rtarget = 100 Ω → Rx = 92.8 Ω
Rtarget = 20 Ω  → Rx = 12.8 Ω
Rtarget = 7.2 Ω → Rx = 0 Ω
Rtarget = 5 Ω   → Rx = -2.2 Ω
```

不要一开始就测：

```text
Rtarget = 1 Ω
```

---

### 阶段 2：接喇叭，但限制最小阻值

先设置：

\[
R_\mathrm{target}\in[10,100]\,\Omega
\]

确认没有自激、没有异常发热。

---

### 阶段 3：逐步降低最小值

依次尝试：

\[
R_\mathrm{min}=7.2\,\Omega
\]

\[
R_\mathrm{min}=5\,\Omega
\]

\[
R_\mathrm{min}=3\,\Omega
\]

\[
R_\mathrm{min}=1\,\Omega
\]

每一步都记录：

- `SPK` 电压
- `DRV` 电压
- `RSHUNT` 电流
- OPA548 温度
- 喇叭线圈温升
- 是否有 90 Hz 附近自激
- 是否有高频振荡

---

## 19. 第一版不建议做的事情

第一版不要同时加入：

1. 负电阻
2. 负电感
3. 高电流
4. Class-D
5. 自动自适应控制
6. 双正弦大幅度叠加
7. 声学阵列

建议顺序：

```text
V1: 只做 R(t)，不做 -L
V2: 加部分电感补偿，例如 -0.5Le
V3: 加全 -Le 或频段限制 -Le
V4: 做多通道/阵列
V5: 改 Class-D 或离散功率级降成本
```

## 20. 总结版电路关系

最终硬件实现的数学关系是：

\[
R_\mathrm{target}(t)
=
50.5
+
49.5\sin(2\pi f_mt)
\]

或：

\[
R_\mathrm{target}(t)
=
R_b
+
A_1\sin(2\pi f_1t+\phi_1)
+
A_2\sin(2\pi f_2t+\phi_2)
\]

\[
R_x(t)=R_\mathrm{target}(t)-7.2
\]

电流检测：

\[
v_I=5i_p
\]

命令电压：

\[
V_K=\frac{R_x}{10}
\]

乘法器：

\[
V_\mathrm{MUL}
=
\frac{v_I V_K}{10}
\]

后级放大：

\[
V_\mathrm{CMD}
=
20V_\mathrm{MUL}
=
R_x i_p
\]

功率级闭环：

\[
V_\mathrm{SPK}\approx V_\mathrm{CMD}
\]

所以：

\[
V_\mathrm{SPK}\approx R_x(t)i_p
\]

这使动圈电声膜的总电学阻抗变为：

\[
R_e+R_x(t)=R_\mathrm{target}(t)
\]

即实现你要的：

\[
7.2\,\Omega
\rightarrow
1\sim100\,\Omega
\]

并且可以按 \(10\sim1000\,\mathrm{Hz}\) 的单正弦或双正弦叠加实时变化。
